
What your code includes
1. Cinematic HUD: Dark futuristic interface, animated 3D-style sphere, radar, snowfall, system panels and live clock.
2. Voice assistant: Wake word detection using “Hey Ultron”, F8 hotkey, speech recognition and text-to-speech.
3. AI intelligence: Ollama integration using the llama3.2 model.
4. Computer control: Open applications, Google searches, browser tabs, screenshots and shell commands.
5. System monitoring: CPU, RAM, battery and system information.
6. Automation: Auto-clicker, macro recording/playback, auto-typing and AFK ghost mode.
7. Communication: WhatsApp messaging and call-related functions.
8. Entertainment: Spotify controls, jokes and motivational responses.
9. Memory: Stores conversations and remembered facts in ultron_memory.json.
10. Additional systems: Weather, reminders, calculator, clipboard, face detection and self-healing watchdog.
